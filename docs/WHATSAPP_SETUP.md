# رابط الجلسة عبر واتساب

## كيف يعمل النظام
1. الأخصائي ينشئ اجتماعًا من Google Meet بنفسه (https://meet.google.com/new) وينسخ الرابط.
2. في التطبيق: **حجوزاتي ← الحجز المقبول ← «رابط الاجتماع مع المريض»** يلصق الرابط.
3. يضغط **«حفظ وإرسال الرابط عبر واتساب»**.
4. يظهر الرابط للأهل في «طلباتي» مع زر **«الانضمام إلى الاجتماع»**.

لا يوجد أي إنشاء تلقائي للاجتماعات.

## وضعا الإرسال

### 1) بدون إعداد (يعمل فورًا)
يفتح التطبيق واتساب على جهاز الأخصائي، والمحادثة على رقم المريض والرسالة مكتوبة.
الأخصائي يضغط **إرسال** داخل واتساب.
الحالة في التطبيق: **«فُتح واتساب»**. لا يمكن للسيرفر التأكد أن الأخصائي ضغط إرسال.

### 2) إرسال تلقائي من السيرفر (WhatsApp Cloud API، اختياري)
تُرسل الرسالة من رقم واتساب الأعمال الخاص بالتطبيق، وتظهر الحالة **«تم الإرسال»** أو **«فشل الإرسال»**.

المطلوب (مرة واحدة، من حساب Meta for Developers / WhatsApp Business):
1. تطبيق Meta من نوع Business مع منتج **WhatsApp**، ورقم واتساب أعمال موثّق.
2. **قالب رسالة** (Message Template) بفئة *Utility* ولغة العربية، نصه:

   ```
   مرحباً {{1}} 🌷
   تم تجهيز رابط جلسة الاستشارة الخاصة بك مع الأخصائي {{2}}.
   📅 موعد الجلسة: {{3}}
   🔗 رابط الدخول إلى الجلسة:
   {{4}}
   نتمنى لكم جلسة موفقة ❤️
   فريق أُعبر Uabber
   ```
   انتظر حتى تصبح حالته **Approved**.
3. رمز وصول دائم (System User Token) بصلاحية `whatsapp_business_messaging`.
4. أضف في Render ← Environment:

   | المتغير | القيمة |
   |---|---|
   | `WHATSAPP_TOKEN` | رمز الوصول الدائم |
   | `WHATSAPP_PHONE_NUMBER_ID` | معرّف رقم الهاتف (Phone number ID) |
   | `WHATSAPP_TEMPLATE_NAME` | اسم القالب كما في Meta |
   | `WHATSAPP_TEMPLATE_LANG` | رمز لغة القالب، غالبًا `ar` |

بدون هذه المتغيرات يبقى الوضع (1) يعمل.

## الحماية من التكرار
- محاولة إرسال واحدة كل 10 ثوانٍ لنفس الحجز (ضد الضغط المتكرر).
- إذا أُرسل نفس الرابط بنجاح عبر API، لا يُعاد إرساله إلا بزر «إعادة الإرسال».
- تغيير الرابط أو موعد الجلسة يعيد الحالة إلى «لم يُرسل» حتى يُرسل من جديد.
